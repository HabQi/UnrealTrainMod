# UnrealTrainMod

一个正在开发中的 Minecraft 1.21.1 / NeoForge 列车模组，支持从 RTM 资源包加载静态 MQO 车辆和轨道模型，从沉浸铁路（IR）资源包加载静态 OBJ 车辆。

- 直接加载 RTM 资源包 ZIP，显示车体、转向架及基础材质与贴图。
- 直接加载 IR 资源包 ZIP 的 JSON 车型目录、OBJ/MTL 和默认涂装，与 RTM 车辆共用预览和放置功能。
- 提供车辆放置器，可搜索车型并进行三维预览，支持旋转、平移和缩放。
- 支持在世界中放置和拆除车辆，车辆随世界保存。
- 提供“车辆”物品，复用车型选择与预览界面，可在 UTM 轨道上放置车辆并贴合轨道方向和坡度；支持生存模式消耗、拆除返还及联机显示。
- 支持基础颜色、透明度、单双面及平滑法线，使用共享静态 GPU 网格渲染。
- 支持原生直线和三次贝塞尔轨道，显示钢轨与轨枕，轨道随世界保存。
- 支持三点自定义水平道岔，两支线路可用扳手调整贝塞尔曲线，并使用所选 RTM 轨道模型铺设；支持世界预览、扳手切换、状态保存同步、车辆选路、整组占用保护及反向挤岔后自动恢复，保留命令创建左右开标准道岔。
- 提供轨道施工工具、曲线参数扳手与轨道铺设器，可施工直线、曲线及坡道，支持独立竖向贝塞尔纵断面和平滑变坡，选择 RTM 静态模型进行铺设。
- 提供钢锯拆轨、列车轨道占用保护、同段冲突报告和运行诊断显示。
- 提供实时线路地图，可查看当前维度全图、列车位置、道岔开通方向、轨道占用及同段冲突。
- 提供管理员轨道调试命令，按玩家接收的区块同步轨道，创建与拆除实时更新显示。
- 支持单车及同向双车沿轨正反运行、闭环连续运行、车体与转向架姿态及道岔切换后的在线选路；尚未实现车门动画和 RTM 脚本执行。
