# UnrealTrainMod

一个正在开发中的 Minecraft 列车模组，目前支持加载 MQO 模型并在游戏中展示 YZ25G 客车。

- 使用模型放置器放置和拆除模型，展示实体随世界保存。
- 支持贴图、材质颜色、透明度及平滑法线。
- 不透明和镂空部分使用共享静态 GPU 网格。
- 当前为静态展示阶段，尚未实现列车行驶、轨道适配和 OBJ 加载。

操作方法、资源配置、渲染实现及当前限制见 [STATUS.md](STATUS.md)。
